
# RIMBARA

### National Forest Fire Analysis System

RIMBARA is a web-based forest fire identification
and burn severity analysis system using Sentinel-2
satellite imagery and the Differenced Normalized
Burn Ratio (dNBR) method.

## Project Overview

RIMBARA aims to identify fire-affected areas and
analyze burn severity across Indonesia during
2024–2026.

## Technology Stack

- Next.js
- Laravel
- Python
- Leaflet.js
- PostgreSQL + PostGIS
- Rasterio
- NumPy
- GeoPandas

## Main Features

- National Indonesia Web GIS
- Sentinel-2 satellite imagery processing
- Normalized Burn Ratio (NBR)
- Differenced Normalized Burn Ratio (dNBR)
- Burn severity classification
- Spatial analysis and visualization

## Project Structure

- backend: Laravel REST API
- frontend: Next.js Web GIS
- image-processing: Python processing engine
- data: Satellite imagery and geospatial data
